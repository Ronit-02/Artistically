# Application fonts

These unmodified WOFF2 assets preserve the application's existing typography and
load from the application origin under its Content Security Policy.

- Inter: Google Fonts CSS API, normal weights 300–700 and italic weights 300–400,
  with the original language subsets and optional display behavior. License:
  `Inter-LICENSE.txt`. Upstream: https://github.com/rsms/inter.
- General Sans: Fontshare CSS API, normal weights 500, 600, and 700. License:
  `GeneralSans-LICENSE.txt`. Upstream: https://www.fontshare.com/fonts/general-sans.

Font files are for this application's own rendered interface. The Fontshare
license does not permit redistribution as a standalone font library.
